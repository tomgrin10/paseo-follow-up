# Paseo Follow-up

Trusted Paseo plugin with separate client, server and shared boundaries. Minimum Paseo is 0.11.0. Use native React Native controls and host theme tokens.

The public name is Follow-up and the npm package is paseo-follow-up. Retain installation id follow-through, RPC names and plugin-data/follow-through for existing installations. Never reset tracked work or settings during an upgrade.

Never commit credentials, daemon state, transcripts or local machine paths. Boolean configuration uses positive enable_ names. Subprocesses use argument arrays without a shell.

Run npm run verify, npm run test:install and npm pack --dry-run. Integration checks use isolated Paseo/provider homes and synthetic agents. Never restart the user's daemon or send test messages into real conversations.

Server MCP and hook source files are generated by scripts/build.mjs. Include generated output when changing their scripts. All button settings live in the host-scoped Display preferences and preserve older saved sidebar values.

Publish from a clean main with matching package/lock versions and an immutable vX.Y.Z tag. The npm workflow uses Trusted Publishing; never move a published tag. Wait for registry integrity verification before claiming npm publication. See README.md for setup and OVERVIEW.md for data access and automation boundaries.
